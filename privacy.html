Privacy Policy

Shorts Studio · last updated 16 October 2026

Who uses it

Shorts Studio is a personal tool used only by its owner to publish videos to the owner's own YouTube channels and TikTok accounts.

What data it accesses

With the owner's Google permission it uses:

  • YouTube Data API to upload videos and read the channel's name and video statistics (views, likes, comments);
  • YouTube Analytics API to read audience statistics of the channel's own videos (average view percentage and retention).

It does not access any other Google data, and no data about other people or other channels.

TikTok

With the owner's TikTok permission it uses:

  • Login Kit (scope user.info.basic) to show which of the owner's TikTok accounts is connected;
  • Content Posting API (scope video.publish) to post videos the owner has approved to that account, and to read the post's status.

It does not read followers, messages, other videos or any data about other TikTok users.

Where data is kept

Google and TikTok login tokens and the statistics are stored only on the owner's own computer. Nothing is stored on any server run by Shorts Studio.

Sharing

No data is sold, shared with or transferred to anyone. Shorts Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. TikTok access can be removed in the TikTok app under Settings and privacy → Security → Apps and services. Deleting the local token files removes all stored login data.
