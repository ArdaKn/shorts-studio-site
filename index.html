Shorts Studio

Shorts Studio is a personal tool that makes short videos (data and geography quizzes, rankings and physics simulations) and uploads them to its owner's own YouTube channels and TikTok accounts.

It uses the YouTube Data API to upload videos to channels the owner has logged in, and the YouTube Analytics API to read those channels' view statistics. It is not offered to the public and does not access anyone else's account.

On TikTok it uses Login Kit (to connect the owner's own accounts) and the Content Posting API (to post a video after the owner has reviewed and approved it).
